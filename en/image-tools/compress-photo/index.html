Change the file size, not the meaning of your photo

A photo can be too large for an upload form even when it looks small on screen. This compressor changes the JPG encoding to work within your chosen byte limit. The width and height stay unchanged unless you explicitly allow a smaller image.

Start with the original file rather than a photo that has already been compressed several times. After processing, use Output preview and look at important details such as a face, small lettering or a high-contrast edge. A file that fits the limit still needs to be readable.

100 KB, 200 KB, 500 KB or your own limit

The size presets use decimal units: 500 KB is 500,000 bytes. You can also select KiB when the receiving service explicitly uses binary units. The result shows the actual byte count so you can compare it with the requirement instead of relying on a rounded label.

For a dedicated starting point, use JPG to 100 KB, JPG to 200 KB or photo to 500 KB. These pages have the appropriate limit selected, with guidance for that size. They use the same compression engine.

What happens to the original file?

An already-compliant JPG is returned unchanged when you request compression only. This avoids unnecessary re-encoding. PNG and WebP inputs are converted to JPG; transparent pixels use the selected background colour. Use PNG to JPG if format conversion is your main task.

Processing happens in the browser and does not upload your image to an image-processing server. Choose one file up to 25 MB and 24 megapixels. If the requested cap cannot be reached with the allowed settings, the tool explains the problem rather than offering an oversized file as a successful result.

Questions, answered

Will this preserve every detail?

Not necessarily. JPG compression is lossy. The tool searches for a quality setting within the limit, but you should inspect the output. An already-compliant original JPG is kept unchanged.

Why did the dimensions change?

Dimensions can decrease only when you uncheck Keep original dimensions and the byte cap cannot otherwise be reached. The result reports the new dimensions.

Can I process a transparent PNG?

Yes, but this tool exports JPG. Pick a background colour because JPG cannot keep transparency. Keep the PNG if transparency is essential.
