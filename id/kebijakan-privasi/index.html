Kebijakan privasi

Kebijakan ini menjelaskan perangkat lunak yang disertakan pada rilis Toolmova saat ini.

Diperbarui 2026-10-25

File gambar dan pengolahan

Gambar diolah di browser Anda. Kode alat membaca file yang dipilih, bekerja di memori browser dan membuat hasil yang dapat diunduh. Rilis ini tidak mengirim isi gambar ke server pengolah atau layanan AI.

Pratinjau sementara dan tautan hasil berada pada halaman yang sedang dibuka. Keduanya diganti atau dilepas ketika Anda mengganti file, memulai ulang atau meninggalkan halaman. File unduhan disimpan sesuai pengaturan browser; Toolmova tidak dapat menghapus file yang sudah tersimpan di perangkat.

Metadata dan file asli yang tidak berubah

JPG yang sudah memenuhi batas kompresi dapat dikembalikan tanpa perubahan. Metadata dalam file asli, termasuk kemungkinan informasi lokasi atau perangkat, tetap ada. Jangan memakai alat ini sebagai penghapus metadata.

Hasil yang dikodekan ulang dibuat dari gambar yang telah dibaca. Pengubah ukuran dan preset cetak menyimpan DPI pilihan pada JPG. Lakukan pemeriksaan tersendiri jika penggunaan Anda memerlukan audit metadata yang jelas.

Permintaan ke penyedia hosting

Browser tetap perlu meminta HTML, gaya, skrip dan ikon situs dari penyedia hosting. Penyedia dapat menerima informasi koneksi biasa seperti alamat IP, informasi browser, URL yang diminta dan waktu permintaan. Pengelolaan catatan tersebut bergantung pada penyedia untuk situs yang diterbitkan.

Rilis ini tidak menyertakan skrip iklan, pelacak analitik, permintaan font pihak ketiga atau sistem akun. Penyimpanan browser tidak digunakan untuk menyimpan gambar Anda. Pemilihan bahasa memakai tautan halaman biasa, bukan pengalihan otomatis berdasarkan lokasi.

Email masukan

Jika Anda mengirim email, layanan surat Anda dan penyedia email penerima menangani pesan tersebut. Penerima memperoleh alamat serta isi yang Anda kirim. Hindari dokumen pribadi atau informasi sensitif yang tidak diperlukan.

Pertanyaan tentang rilis ini dapat disampaikan melalui halaman kontak. Jika versi berikutnya menambahkan analitik, iklan, unggahan atau penyimpanan, pemilik situs perlu memperbarui kebijakan sebelum fitur tersebut diperkenalkan.
