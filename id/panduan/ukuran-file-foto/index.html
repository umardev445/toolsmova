Memahami ukuran file foto tanpa menebak

Gambar yang terlihat lebih kecil belum tentu memiliki file lebih kecil. Pisahkan byte, piksel dan format agar pengaturan yang diubah memang tepat.

Diperbarui 2026-10-27 · Oleh Toolmova

Ukuran file menghitung data; dimensi menghitung piksel

Ukuran file adalah jumlah data yang disimpan pada gambar, biasanya ditampilkan dalam byte, KB atau MB. Dimensi piksel adalah lebar dan tinggi, misalnya 1600×1200 piksel. Keduanya menjelaskan sifat berbeda. Tidak ada satu ukuran KB yang pasti untuk sebuah kombinasi lebar dan tinggi.

Pemandangan bertekstur membutuhkan lebih banyak data daripada latar sederhana pada pengaturan JPG serupa. Metadata dan format juga memengaruhi jumlahnya. Karena itu, perubahan dimensi saja tidak dapat menjamin ukuran file tertentu.

KB dan KiB tidak bisa dipertukarkan

Toolmova menyediakan pilihan satuan yang jelas. KB desimal berarti 1.000 byte, sedangkan MB berarti 1.000.000 byte. KiB biner berarti 1.024 byte. Layanan tujuan bisa memakai salah satunya atau menampilkan label yang dibulatkan. Periksa ketentuan yang dinyatakan jika tersedia.

LabelBatas desimalAlternatif biner
100 KB100.000 byte100 KiB = 102.400 byte
200 KB200.000 byte200 KiB = 204.800 byte
500 KB500.000 byte500 KiB = 512.000 byte

Contoh: file yang tampak seperti 100 KB

Bayangkan JPG berisi 100.352 byte. File itu berada di bawah 100 KiB karena 100.352 lebih kecil dari 102.400. Namun, file tersebut melebihi 100 KB desimal karena di atas 100.000. Formulir dengan batas kedua dapat menolaknya meskipun tampilan di tempat lain tampak menyebut 100 KB.

Gunakan jumlah byte sebenarnya agar tidak rancu. Batas maksimal juga tidak mengharuskan hasil tepat sama: 98.000 byte masih sesuai untuk batas 100.000 byte. Menambahkan data pengisi tidak memberi manfaat bagi gambar.

Pilih proses sesuai persyaratan

  • File terlalu besar tetapi dimensi sudah benar: coba kompresi terlebih dahulu.
  • Dimensi piksel tidak sesuai: ubah ukuran sambil menjaga rasio, kecuali perubahan proporsi memang diinginkan.
  • Bentuk salah atau latar berlebihan: potong secara sengaja, lalu periksa lagi ukuran file.
  • Sumber PNG tetapi tujuan meminta JPG: lakukan konversi dan pilih latar untuk transparansi.

Mulai dari batas terbesar yang berguna

Jika tujuan mengizinkan 500 KB, mulai dari batas itu daripada langsung memaksa hasil 100 KB. Anggaran lebih besar dapat menyisakan ruang untuk detail, tetapi kualitas pratinjau tetap harus dinilai terpisah. Pilih 500 KB, 200 KB atau 100 KB berdasarkan ketentuan sebenarnya.

Simpan sumber asli. Menyimpan ulang JPG yang telah dikompres dapat menambahkan artefak. Mode kompresi saja di Toolmova mengembalikan JPG yang sudah sesuai batas tanpa perubahan; metadata aslinya pun tetap dipertahankan.

Saat target ukuran tidak mungkin dicapai

Perubahan kualitas memiliki batas. Gambar beresolusi tinggi dan penuh detail mungkin tidak dapat masuk ke batas sangat kecil tanpa mengecilkan dimensi atau kehilangan detail penting. Toolmova memberi tahu kondisi itu, bukan menandai hasil yang terlalu besar sebagai sesuai.

Naikkan batas jika diizinkan, buang latar tidak perlu lewat crop yang disengaja, atau izinkan gambar lebih kecil hanya jika dimensi hasil masih diperbolehkan. Jangan mengorbankan tulisan atau informasi dokumen yang diwajibkan hanya demi angka file lebih kecil.

Daftar pemeriksaan sebelum mengunggah

  • Pastikan file unduhan benar-benar memakai format yang diminta; mengganti ekstensi bukan konversi.
  • Bandingkan jumlah byte dengan batas maksimal tujuan.
  • Periksa lebar, tinggi, rasio dan dimensi minimal secara terpisah.
  • Buka file unduhan dan periksa wajah, tulisan serta tepi objek.
  • Simpan sumber asli dan ikuti aturan terbaru tentang isi serta latar foto.

Pertanyaan umum

Apakah foto 200 KB bisa memiliki dimensi apa saja?

Banyak dimensi berbeda dapat masuk ke anggaran tersebut, tetapi layanan tertentu mungkin menetapkan lebar dan tinggi sendiri. Periksa kedua ketentuan secara terpisah.

Apakah mengganti nama PNG menjadi JPG mengecilkan file?

Tidak. Penggantian nama tidak mengodekan ulang gambar. Gunakan konverter sungguhan dan periksa file hasilnya.

Mengapa browser berbeda dapat menghasilkan ukuran JPG berbeda?

Pengode JPG browser dapat menghasilkan susunan byte berbeda untuk kualitas yang sama. Pemeriksaan yang penting adalah ukuran file hasil yang sebenarnya, dan itulah yang ditampilkan Toolmova.
