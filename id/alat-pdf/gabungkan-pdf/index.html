Pertanyaan umum

Apakah urutan halaman berubah?

Urutan file mengikuti kartu dari kiri ke kanan, lalu baris berikutnya. Urutan halaman di dalam setiap file tetap.

Apakah ini mengompres PDF?

Tidak. Penggabungan menyatukan halaman dan tidak menjamin ukuran lebih kecil.

Bagaimana dengan formulir dan tanda tangan digital?

Alat ditujukan untuk dokumen halaman biasa. Jangan gunakan hasil untuk mempertahankan validitas tanda tangan digital, lampiran atau formulir interaktif; periksa dokumen asli di aplikasi khusus.

Berapa batasnya?

Maksimal 25 file, 50 MB per PDF, total 100 MB dan 200 halaman. Kemampuan perangkat juga memengaruhi pemrosesan.
