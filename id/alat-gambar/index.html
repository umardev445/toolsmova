PANDUAN PRAKTIS

Memahami ukuran file foto tanpa menebak

Gambar yang terlihat lebih kecil belum tentu memiliki file lebih kecil. Pisahkan byte, piksel dan format agar pengaturan yang diubah memang tepat.

PANDUAN PRAKTIS

Dimensi foto: piksel, sentimeter dan DPI

Petunjuk ukuran foto yang berguna memerlukan satuan. Rasio, sentimeter dan batas byte menjawab pertanyaan yang berbeda.

Tanpa unggah gambar

Kompresi, pemotongan dan konversi berlangsung di browser. Tidak ada server pengolah gambar.

Tanpa akun

Buka alat, pilih pengaturan dan unduh hasilnya. Tidak perlu mendaftar atau berlangganan.
